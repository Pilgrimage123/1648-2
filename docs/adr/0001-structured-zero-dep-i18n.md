# Structured Simulation Log and Zero-Dependency Typed i18n

Simulation state (`Sim`) stores language-agnostic identifiers and structured combat log descriptors (`LogEntry`) rather than pre-formatted localized strings, and all user-facing text is resolved at projection/render time through a zero-dependency typed `src/i18n/` module. Because Slavic languages (such as Czech) require grammatical case inflection (accusative, instrumental, dative) and 3-way pluralization rules (`1`, `2–4`, `5+`) that depend on both the sentence template and the unit identity, typed locale formatter functions provide compile-time safety without external runtime dependencies while allowing players to switch languages mid-mission and see existing combat log history, unit statuses, and epilogues re-render immediately.
